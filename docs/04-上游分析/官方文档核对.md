## 1. Android 原生库加载（改 .so 相关必读）

来源：Android Developers / Android NDK 官方文档。

### 1.1 命名空间与私有库（API 24+ 强制）

- 自 **API 24** 起强制：原生库只能用公开 API，**不得链接非 NDK 平台库**。
- 由**动态链接器**执行，`System.loadLibrary`、`DT_NEEDED` 条目、直接 `dlopen(3)` **三种方式行为完全一致**，绕不过去。
- `libandroid_runtime.so`、`libcutils.so`、`libcrypto.so`、`libssl.so` 仅对 targetSdk ≤ 23 临时可访问，且会打 logcat 警告。
- 公开库清单：`/vendor/etc/public.libraries.txt`（芯片厂商）、`/system/etc/public.libraries-COMPANYNAME.txt`（设备厂商）。
- 厂商公开库必须命名为 `lib*COMPANYNAME.so`；**AOSP 自带的库不得被公开**（标准公开库除外）。

### 1.2 manifest 声明（API 31+ 强制）

- targetSdk **31（Android 12）及以上**，必须在 manifest 用 `<uses-native-library>` 显式声明原生共享库依赖。
- 声明的库若在设备上不存在 → **应用无法安装**。
- 安装后只能拿到已声明的那些库。

→ 对本项目的影响：玩家自带 .so 属于运行时加载，不走 manifest 声明路径，但**不得依赖任何非 NDK 平台库**，否则在 API 24+ 必崩。

### 1.3 JNI 官方建议

- 在**静态类初始化器**里调 `System.loadLibrary`。
- 参数是**去修饰名**：`libfubar.so` → `"fubar"`。
- 官方推荐 `JNI_OnLoad` + `RegisterNatives`，用版本脚本或 `-fvisibility=hidden` **只导出 `JNI_OnLoad`**：更快更小，避免与其他库符号冲突（代价是 native 崩溃栈信息变少）。
- `JNI_OnLoad` 里调 `FindClass` 会使用该 .so 加载时所用的 classloader 上下文。
- 官方文档原文点名 **ReLinker** 用于规避 PackageManager 安装/更新原生库不可靠的 bug。
- `System.load(完整路径)` 也是合法方式。

### 1.4 打包与解压

- `extractNativeLibs=false` 自 API 23 起可用，.so 需 **4096 字节页对齐且未压缩**。
- API 23+ `dlopen` 可直接从 zip 打开：路径形如 `my_zip_file.zip!/libs/libstuff.so`。
- API 23 起才区分 soname 与 path；更早版本拿 basename 当 soname，同名库互相顶替。

## 2. Minecraft 版本清单

来源：Minecraft Wiki（version_manifest.json 条目）+ 启动器 API 结构文档。

端点：`https://piston-meta.mojang.com/mc/game/version_manifest_v2.json`

```
latest.release   最新正式版版本 ID
latest.snapshot  最新快照版本 ID
versions[]       id / type / url / time / releaseTime / sha1 / complianceLevel
```

- `type` 取值：`release` / `snapshot` / `old_beta` / `old_alpha`
- 另有 pre-release 与 release candidate，命名形如 `1.xx.yy-prek`、`1.xx.yy-rck`
- `versions` 数组顺序：**新 → 旧**
- 拿到 `url` 后下载版本 json，用 SHA-1 校验并与 `sha1` 字段比对
- **`complianceLevel` 为 0 时，启动器应警告用户**：该版本过旧，不支持最新玩家安全特性

→ 对本项目的影响：`complianceLevel == 0` 必须给出可见提示，不能静默跳过。

**未亲验**：沙盒网络受限，未实际请求该端点。以上为文档结构，非实测响应。

## 3. Modrinth

来源：`docs.modrinth.com/api/`（官方）。

### 3.1 限流与 UA

- **300 次/分钟**，按 IP，有无 token 都一样。
- 响应头：`X-Ratelimit-Limit` / `X-Ratelimit-Remaining` / `X-Ratelimit-Reset`
- **必须提供唯一标识的 User-Agent**。只带 `okhttp/4.9.3` 这类库标识会提高被封概率。
  推荐格式：`github_username/project_name/1.56.0 (contact@...)`
- 绝大多数请求**不需要 token**；只有创建/修改数据、访问私有数据才需要。
- 无效 scope 返回 401。

### 3.2 版本策略

- 破坏性变更时 URL 路径里的版本号 +1，并发布迁移步骤。
- 旧版本立即视为 deprecated，**彻底弃用后永久返回 410**。应用必须处理 410。
- 官方会往返回数据里塞 `STOP USING THIS API` 之类的字样催迁移。

### 3.3 关于 v3（重要，当前存疑）

官方文档**本次抓取时**显示：

```
Labrinth (v2.7.0/366f528)
```

且文中表述为"GitHub tokens will cease to function … **as soon as** version 3 of the API is made generally available"（将来时）。文档中**只有 v1→v2 的迁移说明，没有 v3 端点或 v3 迁移指南**。

同时，沙盒网络仅 `api.github.com` 可达，**无法直接请求 `api.modrinth.com/v3/` 验证**（已试，失败）。

→ 判定：**v3 的存在性当前为 NOT PROVEN**，官方文档与我实际可见的信息存在冲突。

→ 应对（不赌哪一边）：Modrinth 的 **base URL 与 API 版本号一律走配置文件/常量，不硬编码**。默认按 v2 初始化，同时预留 v3 切换位；首次请求若返回 410 或 404 则提示并可切版本。迁移指南发布后按官方步骤改，不自创。

### 3.4 标识符

- 项目/版本/用户/团队等用 **8 位 base62 ID**。
- slug 与 username **随时可能变**，长期存储必须用 ID。
- 版本文件用 sha1/sha512 作为标识。

## 7. Minecraft version.json 启动规范

来源：Minecraft Wiki 编写启动器教程。

- `arguments` 下的 `game` / `jvm` 元素不只是字符串，也可能是带 `rules` 的 Map；`libraries` 每一项也可能带 `rules`
- `rules` 字段：`action`（`allow` / `disallow`）、`features`（启动器内布尔设置）、`os`（`name` / `version` / `arch`）
  - 注意：`action: allow` + `os` 条件 = 变相说明只有列出的系统可用
- `assetIndex`：`id` / `size` / `totalSize` / `url`
- `downloads.client` / `downloads.server`：`sha1` / `size` / `url`
- `libraries[]`：几乎都有 `downloads` 与 `name`；natives 通过 `name` 里的分类器区分（如 `natives-windows`），且带 `os` rules
- 字符串含 `${var}` 占位符，使用前需替换

→ 对本项目的影响：
1. `rules` 必须完整求值，不能只按 `os.name` 简单过滤
2. `${var}` 占位符替换不能漏
3. **natives 的提取目录由启动器决定**，这正是本项目让玩家自定义 natives 的介入点，但不得破坏 `rules` 求值结果

**未亲验**：沙盒网络受限，未实际请求 `piston-meta.mojang.com`。

## 8. CurseForge

来源：CurseForge 官方 API 文档 + 第三方整理。

- Base：`https://api.curseforge.com/v1`
- 认证：`X-API-KEY` 头（官方文档另处写作 `X-Api-Token`，以实际生效者为准，**接入时需实测确认**）
- Minecraft 的 `gameId` = **432**
- `classId`：5 = Bukkit 插件；Mod 为另一 classId（**接入时需实测确认**）
- 搜索页 `pageSize` 上限 50
- 响应包裹在 `data` 中，分页信息在 `pagination`

→ 本项目策略：Key 缺省不阻断构建，运行时走 MCIM 镜像（`mod.mcimirror.top/curseforge`，官方结构 100% 兼容可直接替换）。
