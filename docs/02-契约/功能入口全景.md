# 功能入口全景

按「代码里有实现 → 界面上有入口 → 点下去有反应」三层逐项登记。前几十轮补的多是类里的逻辑分支，
装到真机上才发现入口没挂，本表就是为这件事立的台账。核对到代码行的章节标 `<!--✓-->`，
推断与未验证的一律不标，另列在文末。

## 三、条件触发、不是常驻菜单 <!--✓-->

强制停止页、数据导出、开发者策略缓存、账号迁移、远程策略：由启动时判定触发，
不是设置项。其中「强制停止页」的导出是唯一出口，权限未授予时已加应用专属目录兜底。

## 四、本轮补上的入口 <!--✓-->

设置页新增 `FEATURE_CENTER` 一行，点开后：

- **重新填写年龄** → `KcuAgeGate.reset()` + 跳 `KcuAgeActivity`（此前只能在首次启动声明一次）
- **迁移旧目录数据** → `KCUPath.migrateLegacySharedRoot()`，只复制不删源
- 正文列出第二节那批「有实现、没入口」的能力，玩家至少能看到它们存在

## 五、设计稿骨架仍未落地的部分

`ui_main.xml` 目前只有一张版本卡 + 水印；设计稿中的公告卡、空状态、衣柜 8 格、账号卡细节、
桌面端 10 个视图与三段式向导弹窗都还没做。骨架重做须保留 `activity_main.xml` 全部现有 `R.id`。
这是下一轮的工作，不计入本表「已挂入口」。
