# 兜底与降级策略

> 原则：**任何单点失败都不允许导致应用崩溃或无法启动。** 失败必须可见、可诊断、可回退。
> 判定：本文所有条目在实机验证前均为 NOT PROVEN。

---

## 1. 总原则

1. 失败可见。禁止空 `catch`、禁止 `catch` 后返回 `null` 继续跑。每条失败必须进日志并可被用户看到。
2. 失败可回退。任何自定义项失效时，回退到内置默认，而不是中止。
3. 失败可定位。错误信息必须包含：哪个文件、第几步、原始错误（`dlerror` / HTTP 状态 / 异常类名）。
4. 默认路径零污染。玩家不配置时，代码路径与上游一致，不经过任何自定义层。

---

## 2. 分级

| 级别 | 含义 | 处理 | 示例 |
|---|---|---|---|
| L0 致命 | 无法继续 | 明确报错，提示修复方式，不崩 | 无可用 Java 运行时 |
| L1 功能失效 | 该功能不可用，其余照常 | 禁用该功能并提示 | CurseForge 无 Key |
| L2 降级 | 换一条路走 | 自动切换并提示已切换 | 官方源超时走镜像 |
| L3 忽略 | 不影响 | 记日志 | 可选 .so 缺失 |

---

## 3. 逐项兜底

### 3.1 Java 运行时

| 情况 | 处理 | 级别 |
|---|---|---|
| 指定版本不存在 | 按 MC 版本自动挑一个可用版本，提示已切换 | L2 |
| 全部不可用 | 提示安装运行时，给出下载入口 | L0 |
| 用户自带运行时校验失败 | 回退内置，报出失败原因（ABI 不匹配 / 文件损坏 / 缺少可执行文件） | L2 |

### 3.2 .so 与加载顺序

| 情况 | 处理 | 级别 |
|---|---|---|
| `native_load_order.json` 不存在 | 走上游默认流程，不做任何干预 | — |
| JSON 解析失败 | 报错提示文件哪一行有问题，走默认流程 | L2 |
| `abi` 字段与设备不匹配 | 忽略该文件，走默认流程 | L3 |
| `mode = auto` | 打日志"未实现"，走默认流程 | L3 |
| `order` 为空数组 | 走默认流程 | — |
| 列表中某个文件在公共目录不存在 | 按 `required` 决定：true → 中止并报出文件名；false → 跳过并记日志 | L0 / L3 |
| ABI 校验不通过 | 中止该库加载，报出文件名与期望/实际架构 | L0（required=true） |
| `System.load` 抛 `UnsatisfiedLinkError` | 报出序号、文件名、`dlerror` 原文，按 `onFailure` 处理 | 按配置 |
| SHA-256 与私有副本不一致 | 重新复制后加载；复制失败则中止并报出原因 | L0 |

`onFailure`：
- `abort` — 中止启动，展示错误详情
- `skip` — 跳过该库继续
- `fallback` — 丢弃全部自定义库，改用内置默认集

### 3.3 商店与下载源

| 情况 | 处理 | 级别 |
|---|---|---|
| 未填 CurseForge API Key | 自动使用国内镜像，不阻断构建也不阻断运行 | L2 |
| Key 无效 / 401 / 403 | 提示 Key 无效，自动切镜像 | L2 |
| 官方源超时 | 超时阈值后切镜像，提示已切换 | L2 |
| 镜像也失败 | 提示网络问题，保留重试入口 | L1 |
| Modrinth 返回 429 | 读 `X-Ratelimit-Reset`，按指示等待后重试 | L2 |
| 项目无图标（`icon_url` 为 null） | 用占位图，不崩 | L3 |

### 3.4 屏幕抓字

| 情况 | 处理 | 级别 |
|---|---|---|
| 用户未授权 | 功能不可用，不弹骚扰提示 | — |
| MediaProjection 被拒 | 提示需要授权，功能关闭 | L1 |
| 遇到 `FLAG_SECURE` 页面 | 返回空结果并提示该页面不允许截屏，**不绕过** | L3 |
| OCR 失败 / 超时 | 返回空并提示重试 | L3 |
| 端侧模型缺失 | 提示下载或改用在线后端 | L1 |

### 3.5 账号与登录

| 情况 | 处理 | 级别 |
|---|---|---|
| 微软登录链路任一步失败 | 报出是哪一步与服务端返回，不清空已有账号 | L0 |
| XSTS 特定错误码（成年/账号异常） | 给出对应可读提示 | L0 |
| token 过期 | 用 refresh_token 续期；失败则要求重新登录 | L2 |
| 皮肤站不可达 | 提示并使用默认皮肤 | L3 |

### 3.6 存储与权限

| 情况 | 处理 | 级别 |
|---|---|---|
| 公共目录不可写 | 回退私有目录并在设置里提示 | L2 |
| `MANAGE_EXTERNAL_STORAGE` 未授予 | 引导跳设置页，同时提供 SAF 备选路径 | L1 |
| Android 13+ `POST_NOTIFICATIONS` 未授予 | 不影响启动，仅通知不可用 | L3 |

---

## 4. 崩溃兜底

1. 进程级：上游已有 `:crash` 独立进程与崩溃上报 Activity，保留不动。
2. 启动级：连续 N 次启动失败（阈值待定）自动回退到"安全模式"——忽略全部自定义配置，用内置默认启动。
3. 安全模式入口常驻设置页，可手动开关。
4. 安全模式下仍失败 → 导出诊断包（日志 + 配置快照 + ABI + 已加载库列表）供排查。

---

## 5. 诊断输出格式

所有自定义层的关键步骤统一输出这一行格式，便于检索：

```
[KCU] <域> <动作> <目标> <结果> <详情>
```

示例：

```
[KCU] native load  3/5  libmobileglues.so  FAIL  dlopen failed: cannot locate symbol "mgInit" referenced by "libmobileglues.so"
[KCU] mirror switch curseforge -> mcim  OK  key empty
[KCU] runtime select jre21 -> jre17  FALLBACK  jre21 missing
```

---

## 6. 未验证项

以下内容在实机验证前一律标 NOT PROVEN，不得写成 PROVEN：

- 全部 .so 加载顺序行为
- 镜像切换的实际可用性
- 安全模式的触发阈值
- 屏幕抓字的实际耗时与准确率
