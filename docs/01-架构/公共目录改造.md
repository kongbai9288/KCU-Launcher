## 1. API 终点追踪（动手前必做）

改造对象是 `FCLPath.SHARED_COMMON_DIR`。一路追到它最终把数据交给了谁：

```
FCLPath.SHARED_COMMON_DIR            （String 字段，原值 "/sdcard/FCL/.minecraft"）
  ├─ Config.java:149                  commonDirectory 默认值
  ├─ Profiles.kt:80                   Profile.gameDir（仅 profiles 为空时建默认档）
  └─ LauncherSettingPage.java:232     导出日志的父目录
        ↓
FCLGameRepository.changeDirectory(File)
  → setBaseDirectory(File) + refreshVersionsAsync()
        ↓
FCLCacheRepository.setDirectory(String)
  → directory 属性 listener → changeDirectory(Paths.get(t))
        ↓
DefaultCacheRepository.changeDirectory
  → super.changeDirectory(commonDir)
  → librariesDir = commonDir.resolve("libraries")
        ↓
CacheRepository.changeDirectory
  → commonDirectory / cacheDirectory = commonDir.resolve("cache")
  → indexFile = cacheDirectory.resolve("etag.json")
        ↓
【终点】java.nio.file.Files
  Files.isRegularFile / Files.exists / Files.delete / Files.createLink ...
```

### 终点结论

**最后一层是 `java.nio.file.Files`——纯 Java NIO 文件 IO。**

不是 JNI、不是 ContentProvider、不是 native 环境变量、不参与 `dlopen` 或签名校验。

**推论**：`SHARED_COMMON_DIR` 本质上只是"Java NIO 操作哪个路径"的字符串。改它的值不会牵动原生层，改造风险可控。

### 关键附带发现

`Profiles.checkProfiles()` 只在 **profiles 为空**时创建默认档。也就是说：

- 改动 `SHARED_COMMON_DIR` **只影响首次启动**创建的那一个默认 profile
- 已存在用户（profile 从配置反序列化，存的是绝对路径）**不受影响**

这大幅降低了改名的破坏面。

## 2. 本轮改动（FCLPath.java）

新增 `KCU_SHARED_ROOT` 常量，公共目录根由它派生：

| 字段 | 原值 | 新值 |
|---|---|---|
| `KCU_SHARED_ROOT` | — | 新增，`/sdcard/KCU` 或旧 `/sdcard/FCL` |
| `SHARED_COMMON_DIR` | `/sdcard/FCL/.minecraft` | `KCU_SHARED_ROOT + "/.minecraft"` |
| `LOG_DIR` | `/sdcard/FCL/log` | `KCU_SHARED_ROOT + "/log"` |
| `CONTROLLER_DIR` | `/sdcard/FCL/control` | `KCU_SHARED_ROOT + "/control"` |
| `SHARE_DIR` | `/sdcard/FCL/share` | `KCU_SHARED_ROOT + "/share"` |

### 2.1 旧目录兼容（防数据"消失"）

```java
private static String resolveSharedRoot() {
    String external = Environment.getExternalStorageDirectory().getAbsolutePath();
    File legacy = new File(external, "FCL");
    File kcu = new File(external, "KCU");
    if (legacy.exists() && !kcu.exists()) {
        return legacy.getAbsolutePath();
    }
    return kcu.getAbsolutePath();
}
```

**要么全 `/FCL`，要么全 `/KCU`，不会混用。** 从官方 FCL 迁移过来的用户沿用旧目录，数据不丢；全新安装用 `/sdcard/KCU`。
