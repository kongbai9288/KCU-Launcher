## 2. 全文来源：官方 API，不手写

用 GitHub Licenses API `GET /licenses/{key}` 拉取官方发布版本：

| 文件 | 字节 | 响应 key / spdx |
|---|---|---|
| `GPL-3.0.txt` | **35149** | gpl-3.0 / GPL-3.0 |
| `LGPL-2.1.txt` | **26526** | lgpl-2.1 / LGPL-2.1 |
| `LGPL-3.0.txt` | 7652 | lgpl-3.0 / LGPL-3.0 |
| `BSD-3-Clause.txt` | 1499 | bsd-3-clause / BSD-3-Clause |
| `Zlib.txt` | 856 | zlib / Zlib |

**共 71682 字节**，落 `assets/licenses/text/`。

抽查头尾确认是完整协议（GPL-3.0 开头 `GNU GENERAL PUBLIC LICENSE Version 3, 29 June 2007`，结尾完整）。

**为什么不手写**：协议全文是法律文本，任何默写、转述、摘要都可能失真。用官方 API 拿到的就是官方发布的原文。

## 4. 真实编译失败一次：漏 import

run **40080669127** 五架构**全部失败**：

```
KcuLicenseActivity.java:100: error: cannot find symbol
KcuLicenseActivity.java:100: error: cannot find symbol
2 errors
```

**原因**：第 100 行用了 `new Intent(...)`，但文件顶部没有 `import android.content.Intent`。
我加这段代码时只补了逻辑，没同步检查 import。

`KcuLicenseTextActivity` 是同包类所以没报错，只有 `Intent` 找不到 —— 这也说明**同包类不需要 import** 是它没被发现的原因之一。

已补 import，run 40081537478 通过。
