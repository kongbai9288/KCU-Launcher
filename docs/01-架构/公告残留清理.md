## 3. 严格审核

### 3.1 会导致什么错误

| # | 错误 | 处置 |
|---|---|---|
| 1 | **XML 删除踩坑**：第一次按字符串索引找闭合，误判位置，残留了 `hide` 按钮与一个多余闭合标签，ET 解析报 `mismatched tag: line 16` | **重拉原文件**，改用 ElementTree 解析后 `root.remove()` |
| 2 | **ElementTree 写回丢失命名空间前缀**（变成 `ns0:`/`ns1:`）且压成单行 | **手工重写**恢复 `android:` / `app:` 前缀与格式 |
| 3 | 删 `onClick` 后若仍 `implements View.OnClickListener` → 抽象方法未实现，编译失败 | **同步移除** implements |
| 4 | 删 `hide` 字段却保留 `findViewById(R.id.hide)` → 编译失败（找不到符号） | **同步删** |
| 5 | 删 `Announcement.java` 但别处仍引用 → 编译失败 | 全局搜索确认仅 MainUI，且已先删 MainUI 引用 |
| 6 | `ui_main.xml` 删块后若 `watermark` 的约束引用了被删 id → aapt 报错 | 检查确认 `watermark` 约束指向 parent，不依赖被删元素 ✅ |
