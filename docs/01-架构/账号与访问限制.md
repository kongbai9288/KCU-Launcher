## 1. API 终点追踪

### 1.1 登录体系

```
Accounts.FACTORIES = [FACTORY_OFFLINE, FACTORY_MICROSOFT, FACTORY_AUTHLIB_INJECTOR]
  → OfflineAccountFactory.create(selector, username, password, callback, additionalData)
      → additionalData = AdditionalData(uuid, skin)
      → new OfflineAccount(downloader, username, uuid, skin)
          → 【终点】构造器 requireNonNull(uuid)
```

`OfflineAccount` 构造器是 **protected**，外部包无法直接 new，必须走 factory。

### 1.2 关键发现：`create(username, uuid)` 传 null 会 NPE

```java
public OfflineAccount create(String username, UUID uuid) {
    return new OfflineAccount(downloader, username, uuid, null);
}
// OfflineAccount 构造器：this.uuid = requireNonNull(uuid);
```

**传 null uuid 直接抛 NPE。** 必须先算稳定 uuid。这是本轮审核抓出的真 bug（详见 §4.1）。

### 2.1 年龄门槛

- 阈值 `THRESHOLD = 18`
- 未声明 → 跳 `KcuAgeActivity`
- 已声明且低于阈值 → 显示受限页，**不进入主流程**
- 声明值存于配置，随配置持久化

拦截位置在 `SplashActivity.onCreate` 最前，先于协议同意与权限检查——**未声明年龄时不会触发任何权限请求或初始化**。

### 2.2 登录方式开关

开关文件 `<root>/dev_mode`，内容为 `true` 或 `{"developerMode": true}` 视为开启。
**文件不存在或无法解析一律视为关闭。**

### 2.3 按名称解析账号

`KcuAccountFlow.resolve(username, skin)`：

1. 已存在同名账号 → 复用
2. 已存在非离线账号 → 复用
3. 都没有 → 按名称生成本地账号（皮肤可空）

生成的 uuid 走 `OfflineAccountFactory.getUUIDFromUserName`，与上游离线账号规则一致。

## 3. 严格自我审核

### 3.1 会导致什么错误

| # | 错误 | 处置 |
|---|---|---|
| 1 | **`create(username, null)` 抛 NPE** —— `OfflineAccount` 构造器 `requireNonNull(uuid)` | **已修**：先 `getUUIDFromUserName` 算 uuid |
| 2 | `ConfigHolder` 未初始化时读取配置抛异常 | **已防**：`isDeclared`/`isBlocked` 全 try-catch，异常时按未声明处理 |
| 3 | 声明后仍被判为未声明 | 两个条件需同时满足（`prompted && age>0`），写入时一并设置 |
| 4 | 开关文件被误写 | 仅"明确为 true"才开启，其余一律关闭 |
| 5 | 新 Activity 未注册导致崩溃 | 已注册 `android:exported="false"`（非入口） |

### 3.2 对今后使用逻辑的干扰

| # | 干扰 | 状态 |
|---|---|---|
| 1 | **年龄一旦声明无法在应用内修改** | **已知局限**，需后续在设置页加修改入口 |
| 2 | 阈值 18 为常量，不可配置 | 如需按地区调整需改常量 |
| 3 | `KcuAccountFlow` 目前**未被 UI 调用**，仅提供 API | 下一步接入账号创建流程 |
| 4 | `KcuDevMode` 开关尚未接到账号 UI 的可见性控制 | 下一步接入 |
| 5 | 年龄声明页用代码构建 UI，未用揉纸风格 | 后续按设计稿重做 |

### 3.3 设计稿相关

用户提供的揉纸 UI 稿已归档为设计参考。**实例列表不使用图标**（与 FCL 一致），图标栏/公告卡/账号卡/版本卡/启动按钮按稿实现的部分待后续 Compose 迁移时处理。
