# 图标与关于页本地化

> 原则：**一切图标走本地资源，运行时不联网拉取。**
> 理由：离线可用、加载确定、不受上游 CDN 与网络策略影响；同时避免把用户设备信息暴露给第三方图床。

---

## 1. 现状（上游实测）

- `res/drawable` 113 个：`ic_` 68、`bg_` 18、`img_` 16
- 加载器图标已内置：`img_fabric` / `img_forge` / `img_neoforge` / `img_quilt` / `img_optifine` / `img_cleanroom` / `img_legacyfabric`
- 多语言 11 种：`de / fa / ja / pt-rBR / ru / tr / uk / vi / zh / zh-rHK / zh-rTW`，另有 `values-night`、`values-v31`

→ 加载器图标**无需联网**，已满足"商店显示加载器图标"需求。

---

## 2. 规则

### 2.1 禁止

- 不在运行时用 `Glide`/`Picasso` 拉远程头像或项目图标
- 不在开源许可页、开发者页嵌外链图片
- 不用需要联网的字体图标 CDN

### 2.2 必须

- 图标以 `drawable` / `mipmap` / `assets` 形式打包进 APK
- 矢量优先（`vector drawable`），位图按密度提供
- 尺寸与配色走 `res/values`，不硬编码

## 3. 页面设计

### 3.1 关于页

自上而下：

```
[KCU 图标]        ← 本地 mipmap，与 KCU-Migrator 共用 Kcu_icon.png
KCU Launcher
版本 0.5.0 (versionCode 5)

构建信息
  上游提交   cd14d179...
  构建时间   2026-10-19
  ABI        arm64-v8a
```

### 3.2 开源许可页（全部本地）

条目结构：

| 字段 | 来源 |
|---|---|
| 项目名 | 本地 `strings.xml` |
| **图标** | **本地 drawable** |
| 许可证 | 本地 `assets/licenses/<项目>.txt` 全文 |
| 项目地址 | 文本，点击跳浏览器（不加载图片） |

必须收录（含图标）：

| 项目 | 许可证 | 图标 |
|---|---|---|
| FoldCraftLauncher（上游基座） | GPL-3.0 | 本地 |
| PojavLauncher（间接） | LGPL-3.0 | 本地 |
| HMCL（间接，fclcore 来源） | GPL-3.0 | 本地 |
| Android-OpenJDK-Build（JDK 来源） | GPL-2.0 with Classpath Exception | 本地 |
| Terracotta（联机模块） | 按上游 | 本地 |
| SDL3 | Zlib | 本地 |
| LWJGL | BSD-3-Clause | 本地 |
| 其余 Maven 依赖 | 各自许可证 | 统一占位图标 |

许可证全文放 `assets/licenses/`，列表从本地 JSON 读取，**不请求任何远程接口**。

### 3.3 开发者页（带图标）

按用户要求：**每一项前面都要有图标，包括上游项目。**

```
[图标] 项目维护
  kongbai9288

[图标] 上游项目
  [FCL 图标]    FoldCraftLauncher
  [FCL 图标]    Android-OpenJDK-Build

[图标] 图标来源
  [Migrator 图标] KCU-Migrator（Kcu_icon.png）
```

图标全部本地。

## 4. 实施步骤

1. 建立 `res/drawable/` 下的项目图标集（FCL、Pojav、HMCL、OpenJDK、SDL、LWJGL、Migrator）
2. `assets/licenses/` 存放各许可证全文
3. `assets/credits.json` 描述条目与图标映射（本地读取）
4. 关于页/许可页/开发者页共用同一个列表渲染组件（**复用单一模块**，符合既有约定）
5. 图标来源须为各项目官方素材，且许可证允许再分发——**采用前逐个核对许可证**
