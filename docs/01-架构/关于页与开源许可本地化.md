## 2. 追溯：关于页原来什么样

`AboutPage.kt` 的 `LINKS` 共 6 条，**全部指向上游**：

| 条目 | 原链接 |
|---|---|
| about_launcher | fcl-team.github.io |
| about_developer | github.com/FCL-Team |
| community_discord | discord.gg/… |
| community_qq | QQ 群 |
| about_sponsor | afdian.com/@tungs（**上游作者赞助**） |
| about_source | github.com/FCL-Team/FoldCraftLauncher |

**三个问题**：① 没有图标；② 没有开源许可入口；③ 我们是 KCU，关于页却全在推上游。

`item_about.xml` 原布局：title | spacer | jump 箭头，**左侧无图标位**。

## 3. 改动

### 3.1 图标：字符徽章，零联网、零新 drawable

沿用 v0.43.0 的 KcuUi 方案。新增 `KcuUi.badgeBackground()` 供独立图标视图复用，
`iconBadge()` 内部复用同一实现。

`item_about.xml` 加 32dp 图标位，`app:auto_text_tint="false"` + 白色文字
（否则会被主题 tint 成黑字压在强调色底上，v0.22.0 的同类问题）。

### 3.2 关于页重排为三组

| 组 | 条目 |
|---|---|
| 本应用 | KCU 启动器、源代码仓库、QQ 交流群 |
| 上游与开源组件 | FCL、PojavLauncher、HMCL、Android-OpenJDK-Build、SDL3、LWJGL、MobileGlues |
| 许可 | 开源许可（打开本地页） |

**移除了上游赞助入口** —— 我们不是上游，不该引导用户去赞助上游作者。

### 3.3 开源许可页：`KcuLicenseActivity`

数据来自 `assets/licenses/licenses.json`，**读取与展示全程零网络请求**。

SPDX 标识**逐项取自 GitHub API 官方 `license.spdx_id` 字段**，不凭印象填：

| 项目 | SPDX | 来源 |
|---|---|---|
| Fold Craft Launcher | GPL-3.0 | API（5032★） |
| PojavLauncher | **LGPL-3.0** | API（9456★） |
| HMCL | GPL-3.0 | API（10652★） |
| SDL3 | Zlib | API（16869★） |
| LWJGL | BSD-3-Clause | API（5476★） |
| MobileGlues | LGPL-2.1 | API（225★），与 v0.36.0 二进制证据一致 |

**两个查不到的，如实标注而非猜测**：

- `Android-OpenJDK-Build` —— 官方仓库 license 字段为 None，标注"官方仓库未声明 SPDX"
- `Terracotta` —— 搜索确认不到对应仓库，**直接不列入清单**

## 4. 严格审核

### 4.1 会导致什么错误

| # | 错误 | 处置 |
|---|---|---|
| 1 | **Kotlin 顶层函数无法用 `import com.mio.util.openLink`** | 顶层函数编译为 `AndroidUtilKt` 静态方法，已改 `AndroidUtilKt.openLink` ✅ |
| 2 | **Activity 未在 Manifest 注册** → `startActivity` 崩溃 | 已注册，`exported="false"` ✅ |
| 3 | 图标位被主题 tint 成黑字 | `auto_text_tint="false"` + 白色 ✅ |
| 4 | `optJSONObject(i)` 返回 null → NPE | buildRow 开头判空 ✅ |
| 5 | 嵌套 card 内边距过挤 | 行容器改用无背景 LinearLayout ✅ |
| 6 | assets 读取异常 | try-catch 返回 null，显示占位 ✅ |
| 7 | 字符串资源缺失 | 新增 3 条，XML 校验通过 ✅ |

### 4.2 对用户使用逻辑的影响

| 路径 | 结果 |
|---|---|
| 打开关于页 | 每行左侧有图标徽章 |
| 点"开源许可" | 打开本地页，不联网 |
| 点许可条目 | 跳项目主页（唯一联网动作，且是用户主动） |
| 点项目条目 | 跳对应官方仓库 |

**说明行仍用 `about_desc`** —— 该文案描述的是上游，建议后续替换，本轮未改。

### 4.3 对未来的影响

| # | 影响 | 评估 |
|---|---|---|
| 1 | 新增上游组件时须同步 licenses.json | 否则清单不全 |
| 2 | SPDX 若上游改许可需同步 | 低频 |
| 3 | `about_desc` 仍是上游文案 | 遗留，见 §6 |

### 4.4 对代码逻辑的影响

`KcuUi` 新增一个方法，其余为新增文件与资源，未改已有 API 签名。
