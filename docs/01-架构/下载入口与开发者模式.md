## 1. 你要的那个文件

**文件名：`dev_mode`**（无扩展名，全小写）

**位置：`/sdcard/KCU/dev_mode`**

也就是 `.minecraft` 的**同级目录**（`.minecraft` 在 `/sdcard/KCU/.minecraft`）。

**判定：文件存在即开启，不看内容。** 删掉即关闭。

```
/sdcard/KCU/          ← 公共根
├── dev_mode          ← 这个文件，存在即开启开发者模式
├── .minecraft/
├── manifest.json
├── natives/
├── control/
├── log/
└── share/
```

若根选为 `/sdcard/FCL`（迁移用户），则路径为 `/sdcard/FCL/dev_mode`。

## 2. API 终点追踪

### 2.1 下载入口

```
MainActivity.onSelect(view) → when (view) → download 分支
  → uiManager.switchUI(uiManager.downloadUI)
      → DownloadUI.onCreate
          → VersionInstallPage（游戏安装）
          → DownloadPage（mod/整合包/资源包/地图/光影）
          → FavoritePage（收藏）
```

另一条入口：

```
MainActivity.applyPendingOpenDownload()
  → uiManager.switchUI(uiManager.downloadUI) + openDownloadPanel()
```

**两处都已拦截。**

### 2.2 版本目录终点

```
DefaultGameRepository.getVersionRoot(id)
  → new File(getBaseDirectory(), "versions/" + id)
```

导入文件写入 `<gameDir>/versions/<id>/<id>.jar`，与上游结构一致。

### 3.1 关闭状态（默认）

点左侧「下载」→ 打开**导入页**，不进入原下载页。

导入页提供两种方式：

1. **按地址获取**：填版本标识 + 文件地址 → 下载写入
2. **选择本地文件**：填版本标识 → 系统文件选择器 → 复制写入

### 3.2 开启状态

左侧「下载」→ 原 `downloadUI`（版本安装、mod、整合包、资源包、地图、光影、收藏）。

## 4. 严格自我审核

### 4.1 会导致什么错误

| # | 错误 | 处置 |
|---|---|---|
| 1 | **Kotlin `return` 在 `binding.apply{}` 内是非局部返回**，语义依赖内联，易误读且后续改动可能出错 | **已改**为 if-else 显式分支 |
| 2 | `applyPendingOpenDownload` 是**第二条入口**，只拦截菜单会导致它绕过判定直接进下载页 | **已拦截** |
| 3 | 令牌校验在网络不可用时会抛异常 | **已防**：全 try-catch，异常一律返回 false |
| 4 | `verifyOwner` 只做子串匹配可能被伪造响应骗过 | 仅限 https + 200 + 响应含 `"login"` 与预期名；风险已记录 |
| 5 | 导入页未填标识就点按钮 | **已防**：前置校验并提示 |
| 6 | `Profiles` 未就绪时取 gameDir 抛异常 | **已防**：`targetFile` try-catch 返回 null → 提示目录不可用 |
| 7 | 主线程做网络/文件 IO | **已防**：单线程 `ExecutorService`，UI 更新走 `runOnUiThread` |

### 4.2 对今后使用逻辑的干扰

| # | 干扰 | 状态 |
|---|---|---|
| 1 | **导入页只写 jar，不写版本 json** —— 导入的版本不会出现在版本列表，需用户自行准备 | **已知局限**，后续补 json 导入 |
| 2 | 其他入口（如 `LocalModpackPage`、整合包相关页）仍可能 `switchUI(downloadUI)` | 未全覆盖，需后续排查 |
| 3 | 开发者模式开启后**无 UI 提示当前处于该模式** | 后续需在设置页显示状态 |
| 4 | `clearMarks()` 目前**未被 UI 调用**，仅提供 API | 下一步接入设置页 |
| 5 | 清除标记会连带清除年龄声明 | 这是预期行为，但用户需知道会重新弹年龄页 |

### 4.3 令牌校验说明

`verifyOwner` 调 `GET https://api.github.com/user`，带 `Authorization: Bearer <token>`。
仅当返回 200 且响应体含 `"login"` 与 `kongbai9288` 时通过。

**网络不可用 / 非 200 / 令牌无效 → 一律不通过**，不清除任何东西。
