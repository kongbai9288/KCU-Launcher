## 3. 严格审核

### 3.1 会导致什么错误

| # | 错误 | 处置 |
|---|---|---|
| 1 | 只删方法不删 case → 编译失败（找不到方法） | **同时删**，已验证 0 残留 |
| 2 | 只删 case 不删方法 → 死代码残留 | **同时删** |
| 3 | `ThemePreference` 删四色字段后，旧 `theme.json` 含未知字段 | kotlinx.serialization 默认**忽略未知字段**，走 `defaultValue`；`SerializationException` 已捕获回退 |
| 4 | `ThemeData` 的 `color2` / `colorAlpha` 字段仍在（87 个 View 用 `getColor2()`） | **不能删**：`ThemeData` 是运行时数据类，字段被派生方法使用 |
| 5 | `refreshTheme` / `setCloseSkinModel` / `setAnimationSpeed` 分支被误删 | **未动**，仍活跃 |
| 6 | 删 `checkAnnouncement` 实现后 `announcementContainer` 未初始化就设 GONE | 保留 `findViewById`，仅改方法体 |

### 3.2 对用户使用逻辑的影响

| 路径 | 结果 |
|---|---|
| 设置 → 主题 | 无配色项（v0.26.0 已删），无残留空分组 ✅ |

| 设置 → 光标 / 菜单图标 | 仍在 ✅ |

| 全屏 / 皮肤模型 / 动画速度 | 仍生效 ✅ |
| 亮暗模式 | 仍生效 ✅ |

### 3.3 对未来的影响

| # | 影响 | 评估 |
|---|---|---|
| 1 | 首页不再有官方公告入口 | 未来若需自家公告，应走自建端点而非复用上游域名 |
